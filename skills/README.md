# Skills Hub

This folder is the preferred browsing entry point for repo-local skills.

Use repo-local skills first when a workflow is specific to this commerce codebase. Use global skills mainly for cross-repo tools such as Playwright, Figma, deployment, docs lookup, or specialist one-off tasks.

Current repo-local priorities:

- `brainstorming` -> required before creative implementation work
- `frontend-design` -> repo-aligned frontend design workflow
- `solito` -> repo-specific Solito v5 workflow for this monorepo
- `ui-visual-validator` -> visual verification for UI changes
- `web-design-guidelines` -> UI review and accessibility guidance

Notes:

- The repo-local `solito` skill is the source of truth for Solito work in this workspace.
- The global `solito-v5-shared-ui` skill is legacy guidance and should not be treated as authoritative for this repo unless it is updated.
- Duplicate global skills with the same name should not override repo-local behavior.
