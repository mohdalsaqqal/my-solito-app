# Impeccable Design Context

> **AGENTS.md is the source of truth** for all architecture rules, data-flow principles, and UI contracts. This file contains only Impeccable-specific operational notes. Do not duplicate architecture rules here — reference AGENTS.md instead.

## Design Context

- **Users**: Women 18-40 shopping a cosmetics marketplace (~15,000 products).
- **Brand**: Mass-market commercial beauty. Reference: niceonesa.com. NOT luxury-editorial (anti-references: Aesop, Glossier).
- **Typography**: Manrope (sans-serif) for Latin, Tajawal for Arabic.
- **Dense commercial layout** — compact, conversion-oriented, high information density.

## Color Palette

- Primary CTA: `#222222` (dark neutral) with white text
- Purchase intent: `#a8000d` (deep blood red — buy/add-to-cart only)
- Shell surfaces: `#f9f9f9`, `#ffffff`, `#f3f3f3` (light neutral)
- Status: Green (success), Gold (warning), Red (danger/error/sale), Blue (info)
