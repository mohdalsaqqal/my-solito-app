### Engineering Implementation Specification: Solito v5 \+ UniWind Unified Design System \#\#\#\#\# 1\. Global Monorepo Architecture & Design Constraints In a Solito v5 monorepo, the establishment of a "Single Source of Truth" within packages/ui is a strategic mandate. By decoupling visual primitives from the domain-driven logic in packages/app, we ensure complete performance parity between Next.js (Web) and Expo (Native). This architecture allows the Lead Architect to enforce strict design tokens across platforms while permitting packages/app/features to handle the heavy lifting of state management and navigation. \#\#\#\#\#\# Repository Structure Mapping | Location | Role | Primary Responsibility | | \------ | \------ | \------ | | packages/ui | Shared UI Library | Pure, stateless UniWind components (Atoms/Molecules). | | packages/app/features | Feature Logic | Domain-specific orchestration, hooks, and screen composition. | | packages/app/features/shell | Global Layout | The root navigation wrapper, sidebars, and persistence layers. | \#\#\#\#\#\# Visual Language & Tokens The system implements a global HSL-based token system. Adhering to the *Refactoring UI* principle of "limiting choices," the Base UI is restricted to a grayscale palette: \* **Backgrounds:** hsl(0, 0%, 100%) (White), hsl(0, 0%, 97%) (Soft Grey). \* **Typography/Borders:** hsl(0, 0%, 0%) (Black), hsl(0, 0%, 40%) (Medium Grey). \#\#\#\#\#\# Interaction Rules: The "Accent Red" Constraint **HSL(0, 100%, 50%)** is strictly reserved for interactive feedback. \* **Rule:** Use exclusively for :hover (web) and :active (native) states on primary CTA elements. \* **Constraint:** No static element may utilize this HSL value, ensuring high affordance and zero cognitive ambiguity. \#\#\#\#\#\# RTL Implementation & Logical Properties To ensure global compatibility, all packages/ui components must utilize logical properties via UniWind. \* Replace paddingLeft/Right with paddingStart/End. \* Replace marginLeft/Right with marginStart/End. \* This ensures that the UI automatically flips for RTL locales without platform-specific overrides. These foundational constraints provide the scaffolding for the high-performance layout patterns defined below. \-------------------------------------------------------------------------------- \#\#\#\#\# 2\.
